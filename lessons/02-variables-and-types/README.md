# Class 2: Variables and types

A variable name refers to a value. Assignment with `=` stores a value; `print()` displays it. A quoted name is text: `"price"` prints the word, while `price` uses the variable's value.

Work through examples 01–07 in order. They cover assigning and reusing values, `str`, `int`, `float`, `bool`, checking with `type()`, reassignment, and case-sensitive variable names. Each file runs independently. Example 03 starts with the revised price of 750.

Try `08_your_turn.py`: create a product name, whole-number price, decimal rating, and stock flag. Print the values, change the price, and print the new price. Compare with `09_worked_answer.py` afterward.

## Run a file

Open this folder in VS Code and use **Run Python File in Terminal**, or run a file from a terminal in this folder:

```sh
python 01_price.py
```

On Windows, `py` may be available as an alternative to `python`. These lessons use Python 3 and require no third-party packages. Practice files intentionally produce no output until you add your code.
