# Class 1: Setup and first program

Install [Python](https://www.python.org/downloads/) and [Visual Studio Code](https://code.visualstudio.com/). In VS Code, install Microsoft's Python extension and use **Python: Select Interpreter** to choose your Python installation. Open this lesson folder, create or open a `.py` file, save it, and select **Run Python File in Terminal**.

Python runs your code; VS Code is the editor where you write it. `print()` displays a message. Put text inside matching quotes.

1. Run `hello.py` to display `Hello, Python!`.
2. Run `changed-message.py`, change the text, save, and run again.
3. Create `my_first_program.py` and print `My first program works!`.
4. Compare your solution with `practice-answer.py` after trying it yourself.

## Files

- [changed-message.py](changed-message.py)
- [hello.py](hello.py)

## Run a file

Open this folder in VS Code and use **Run Python File in Terminal**, or run a file from a terminal in this folder:

```sh
python hello.py
```

On Windows, `py` may be available as an alternative to `python`. These lessons use Python 3 and require no third-party packages. Practice files intentionally produce no output until you add your code.

See [expected outputs](EXPECTED_OUTPUTS.md) to check a run.
