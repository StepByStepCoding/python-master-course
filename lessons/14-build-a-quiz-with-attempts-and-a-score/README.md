# Episode 14: Build A Quiz With Attempts And A Score

Matches the November 16 creator recording. Python 3; no third-party packages.

Run `python recorded_example.py` to try the complete example.

## Practice

- Ask: How many values does range(3) give us?
- Add the answer "3" to the answers list.
- A perfect run should show Score: 4/4.
- Test a wrong answer followed by the right answer.

Write your solution in `practice.py`, then compare with `worked_answer.py`.

The quiz accepts two attempts per question. Type q to quit. The score denominator includes all questions. The worked answer adds a fourth question.
